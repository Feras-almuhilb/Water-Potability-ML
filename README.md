# مشروع التنبؤ بصلاحية مياه الشرب (Water Potability Prediction)

## 1. نبذة عن المشروع
في هذا المشروع استخدمت تعلّم الآلة (Machine Learning) لتحليل بيانات جودة المياه والتنبؤ بما إذا كانت عينة المياه صالحة للشرب أم لا، اعتمادًا على مجموعة من الخصائص الكيميائية للمياه.

## 2. مجموعة البيانات (Dataset)
استخدمت مجموعة بيانات Water Potability من موقع Kaggle.

- **عدد السجلات:** 3,276
- **عدد الأعمدة:** 11
- **العمود المستهدف:** `Potability`
- **نوع المهمة:** التصنيف (Classification)

[رابط مجموعة البيانات على Kaggle](https://www.kaggle.com/datasets/adityakadiwal/water-potability)

## 3. تجهيز البيانات (Data Preprocessing)
قبل تدريب النموذج، أجريت بعض عمليات تجهيز البيانات، وهي:

- معالجة القيم المفقودة باستخدام الوسيط (Median).
- إضافة خاصية جديدة باسم `ph_distance` لقياس بُعد قيمة pH عن القيمة المتعادلة 7.
- تقسيم البيانات إلى 80% للتدريب و20% للاختبار.

## 4. النموذج والنتائج (Model & Results)
استخدمت نموذج الغابة العشوائية (Random Forest Classifier) لتنفيذ مهمة التصنيف.

إعدادات النموذج:
- عدد الأشجار: 200
- أقصى عمق للشجرة: 8

نتائج النموذج:
- **دقة التدريب:** 74.9%
- **دقة الاختبار:** 65.5%
- **دقة خط الأساس (Baseline):** 61.0%

أظهرت النتائج أن النموذج حقق دقة أعلى من خط الأساس، مع وجود مجال لتحسين أدائه مستقبلًا.
